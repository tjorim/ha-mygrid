# Architecture

The standalone library declares the entire ModuleTwo map as a typed `Battery(Component)` under `MyGridDevice(Device)`. The planner reads registers 0–17 together; field metadata owns scaling, signed values, writable registers and low-word-first counters. Snapshot validation handles map version, SOC/status validity and telemetry staleness. Device commands own fresh-limit checks and confirmed readback, with no retries.

The canonical integration is in the sibling core contribution overlay, an umbrella over the ModuleTwo and the VoltBridge. This HACS package is generated from its ModuleTwo modules (`moduletwo_*`) with a single-device config flow and its own domain `mygrid_modbus`. It borrows managed units from Home Assistant's `modbus` integration and polls the device for `UpdateReport`s. It performs first refresh before forwarding platforms, derives entity availability from component status, retains lifetime counters with `RestoreSensor`, and retrieves replayable raw diagnostics. Neither the device nor the integration closes another consumer's shared connection.

The HACS package is generated from these two sources. The generator adapts absolute library imports to `.vendor.mygrid_modbus`, creates the custom manifest and English translations, and adapts the same integration tests to the custom namespace. Library Python files are copied byte for byte with their license and SHA-256 hashes. It uses Home Assistant's Modbus dependency and declares no unpublished PyPI requirement. Ordinary installation and tests work without sibling checkouts.

Change source in the library or core overlay, regenerate, and run the standalone metadata check plus the source sync check. The latter requires sibling repositories; the former verifies the shipped package without them. Library release automation uses PyPI trusted publishing only when a reviewed release is explicitly triggered. Core contribution and HACS testing remain separate release paths.

The config-entry schema remains version 1. Identity remains entry-based because the device exposes no serial number. This transport/model refactor does not change entity keys or power sign/units. Physical acceptance remains pending; automated TCP tests use a simulator.
